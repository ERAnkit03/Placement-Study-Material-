WHY LINEAR ALGEBRA IN AI/ML?
---------------------------------------------------------
Linear Algebra is the mathematics of vectors and matrices.
Almost every AI/ML algorithm stores and processes data
using vectors, matrices, and tensors.

Examples:
- Dataset = Matrix
- Image = Tensor
- Features = Vectors
- Neural Networks = Matrix Multiplications

=========================================================
1. SCALARS
=========================================================

Definition:
A single numerical value.

Example:
5
-10
3.14

AI Example:
Learning Rate = 0.01

Key Point:
Has magnitude only.

=========================================================
2. VECTORS
=========================================================

Definition:
An ordered collection of numbers.

Example:
[2, 4, 6]

Explanation:
Represents multiple values together.

AI Example:
Student Features

[Age, Height, Weight]
[20, 170, 65]

Important Terms:
- Dimension = Number of elements
- Magnitude = Length of vector
- Direction = Orientation

=========================================================
3. MATRICES
=========================================================

Definition:
Rectangular arrangement of numbers.

Example:

[1 2]
[3 4]

Explanation:
Rows = Samples
Columns = Features

AI Example:

Age Salary
25  30000
30  50000

This dataset is a matrix.

=========================================================
4. TENSORS
=========================================================

Definition:
Higher-dimensional matrices.

Examples:
Scalar = 0D
Vector = 1D
Matrix = 2D
Tensor = 3D+

AI Example:
RGB Image

Height × Width × Channels

Used in:
TensorFlow
PyTorch

=========================================================
5. VECTOR OPERATIONS
=========================================================

Vector Addition

[1,2] + [3,4]
= [4,6]

--------------------------------------------

Vector Subtraction

[5,4] - [2,1]
= [3,3]

--------------------------------------------

Scalar Multiplication

2 × [1,2]
= [2,4]

--------------------------------------------

Magnitude

Formula:

||v|| = √(x²+y²)

Example:

v = [3,4]

Magnitude = 5

AI Use:
Distance calculations

=========================================================
6. DOT PRODUCT
=========================================================

Definition:
Measures similarity between vectors.

Formula:

a.b = Σ(aᵢbᵢ)

Example:

[1,2] . [3,4]

= (1×3)+(2×4)

= 11

Interpretation:

Large Positive:
Similar Direction

Zero:
Perpendicular

Negative:
Opposite Direction

AI Uses:
- Recommendation Systems
- Similarity Search
- NLP
- Embeddings

=========================================================
7. CROSS PRODUCT
=========================================================

Definition:
Produces a vector perpendicular to both vectors.

Example:

[1,0,0] × [0,1,0]

= [0,0,1]

AI Relevance:
Less important

Mostly used in:
- Robotics
- Graphics
- Computer Vision

=========================================================
8. MATRIX OPERATIONS
=========================================================

Matrix Addition

[1 2]   [5 6]
[3 4] + [7 8]

=

[6 8]
[10 12]

--------------------------------------------

Matrix Multiplication

[1 2] × [3]
          [4]

=

11

AI Use:
Neural Networks

=========================================================
9. SYSTEM OF LINEAR EQUATIONS
=========================================================

Definition:
Multiple equations solved together.

Example:

x+y=5

x-y=1

Solution:

x=3

y=2

AI Use:
Linear Regression

=========================================================
10. IDENTITY MATRIX
=========================================================

Definition:
Matrix equivalent of number 1.

Example:

[1 0]
[0 1]

Property:

AI = A

Explanation:
Does not change matrix.

=========================================================
11. INVERSE MATRIX
=========================================================

Definition:
Matrix equivalent of reciprocal.

Property:

AA⁻¹ = I

Example:

2 × 1/2 = 1

Similar idea.

AI Use:
Linear Regression

=========================================================
12. RANK OF MATRIX
=========================================================

Definition:
Number of independent rows or columns.

Example:

[1 2]
[2 4]

Rank = 1

Reason:
Second row depends on first row.

AI Use:
Feature Reduction

=========================================================
13. DETERMINANT
=========================================================

Definition:
A special value of square matrix.

2×2 Formula:

|A| = ad - bc

Example:

[1 2]
[3 4]

Determinant

= (1×4)-(2×3)

= -2

Interpretation:

Det ≠ 0
Invertible

Det = 0
Not Invertible

=========================================================
14. EIGENVALUES
=========================================================

Definition:
Amount of stretching.

Equation:

Av = λv

λ = Eigenvalue

Example:

Stretch vector by 5

Eigenvalue = 5

=========================================================
15. EIGENVECTORS
=========================================================

Definition:
Direction remains unchanged after transformation.

Example:

Arrow gets longer
Direction stays same

AI Uses:
- PCA
- Face Recognition
- Computer Vision

=========================================================
16. VECTOR SPACE
=========================================================

Definition:
Collection of vectors following vector rules.

Example:
2D Plane

=========================================================
17. SUBSPACE
=========================================================

Definition:
Smaller vector space inside larger space.

Example:
Line passing through origin.

AI Use:
Data often lies in lower-dimensional spaces.

=========================================================
18. BASIS
=========================================================

Definition:
Minimum vectors needed to represent space.

Example:

(1,0)

(0,1)

These can create all 2D vectors.

=========================================================
19. DIMENSION
=========================================================

Definition:
Number of basis vectors.

Examples:

Line = 1

Plane = 2

Space = 3

=========================================================
20. ORTHOGONALITY
=========================================================

Definition:
Vectors at 90 degrees.

Condition:

Dot Product = 0

Example:

(1,0)

(0,1)

AI Use:
PCA

=========================================================
21. PROJECTION
=========================================================

Definition:
Shadow of one vector on another.

Example:
Torch creates shadow.

AI Use:
Feature Extraction

=========================================================
22. MATRIX FACTORIZATION
=========================================================

Definition:
Breaking matrix into simpler matrices.

Example:

A = LU

L = Lower Matrix

U = Upper Matrix

AI Uses:
- Recommender Systems
- Optimization

=========================================================
23. MATRIX NORMS
=========================================================

Definition:
Measures matrix size.

Frobenius Norm:

√(sum of squares)

Example:

[1 2]
[3 4]

Norm = √30

AI Use:
Regularization

=========================================================
24. POSITIVE DEFINITE MATRIX
=========================================================

Definition:

xᵀAx > 0

for every non-zero vector.

Example:

[2 0]
[0 3]

AI Uses:
- Optimization
- Covariance Matrix

=========================================================
25. MATRIX DECOMPOSITION
=========================================================

Definition:
Breaking matrix into simpler components.

Types:
- LU
- QR
- SVD
- Eigen Decomposition

AI Use:
Faster Computations

=========================================================
26. SINGULAR VALUE DECOMPOSITION (SVD)
=========================================================

Formula:

A = UΣVᵀ

Explanation:

U = Left Singular Vectors

Σ = Singular Values

Vᵀ = Right Singular Vectors

AI Uses:
- Image Compression
- Recommender Systems
- NLP

=========================================================
27. PCA
=========================================================

Principal Component Analysis

Definition:
Reduces dimensions while preserving information.

Example:

100 Features

↓

10 Features

Benefits:
- Faster Training
- Less Noise
- Better Visualization

=========================================================
28. SPECTRAL DECOMPOSITION
=========================================================

Formula:

A = PDP⁻¹

P = Eigenvectors

D = Eigenvalues

AI Uses:
- Graph Neural Networks
- Clustering
- PCA

=========================================================
29. ORTHOGONAL MATRIX
=========================================================

Definition:

QᵀQ = I

Meaning:
Transpose = Inverse

Benefits:
Preserves distances and angles.

=========================================================
30. SYMMETRIC MATRIX
=========================================================

Definition:

A = Aᵀ

Example:

[1 2]
[2 3]

AI Uses:
Covariance Matrices

=========================================================
31. COVARIANCE MATRIX
=========================================================

Definition:
Shows relationships between features.

Positive:
Increase Together

Negative:
Move Oppositely

Used In:
PCA

=========================================================
32. TRACE OF MATRIX
=========================================================

Definition:
Sum of diagonal elements.

Example:

[1 2]
[3 4]

Trace = 1+4 = 5

=========================================================
33. SPAN
=========================================================

Definition:
All possible combinations of vectors.

Example:

(1,0) and (0,1)

Span entire 2D plane.

=========================================================
34. LINEAR INDEPENDENCE
=========================================================

Definition:
No vector can be formed from others.

Example:

[1,0]

[0,1]

Independent

=========================================================
35. LINEAR DEPENDENCE
=========================================================

Definition:
One vector is combination of others.

Example:

[1,2]

[2,4]

Dependent

=========================================================
36. CHANGE OF BASIS
=========================================================

Definition:
Representing same vector using another basis.

AI Use:
Coordinate transformations.

=========================================================
37. AFFINE TRANSFORMATION
=========================================================

Definition:
Linear Transformation + Translation.

Examples:
- Rotation
- Scaling
- Translation

Computer Vision uses this heavily.

=========================================================
38. LINEAR TRANSFORMATION
=========================================================

Definition:
Function that maps vectors to vectors.

Examples:
- Scaling
- Rotation
- Reflection

AI Use:
Neural Network Layers

=========================================================
39. KERNEL (NULL SPACE)
=========================================================

Definition:
Vectors mapped to zero.

Ax = 0

AI Use:
Feature Analysis

=========================================================
40. COLUMN SPACE
=========================================================

Definition:
All combinations of matrix columns.

Represents information stored by matrix.
