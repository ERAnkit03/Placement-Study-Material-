# Sample Function for Demonstration

```python id="d3q6hs"
def sinplot(n=10, flip=1):
    x = np.linspace(0, 14, 100)

    for i in range(1, n + 1):
        plt.plot(
            x,
            np.sin(x + i * .5) * (n + 2 - i) * flip
        )
```

# Seaborn Visualization Concepts — Consolidated Study Notes

## 1. Regression & Statistical Visualization

Seaborn provides high-level tools for visualizing statistical relationships, especially linear regression models.

### Core Functions

| Function        | Type         | Purpose                                         |
| --------------- | ------------ | ----------------------------------------------- |
| `sns.regplot()` | Axes-level   | Draw regression on a single matplotlib axis     |
| `sns.lmplot()`  | Figure-level | Combines regression with faceting (`FacetGrid`) |

### Basic Regression Plot

```python
tips = sns.load_dataset("tips")

sns.regplot(
    x="total_bill",
    y="tip",
    data=tips
)
```

```python
sns.lmplot(
    x="total_bill",
    y="tip",
    data=tips
)
```

# 10. Custom Plot Functions in FacetGrid

## Requirements

Custom functions must:

1. Plot on current matplotlib axis
2. Accept positional data arguments
3. Accept `color` and `label`
4. Ideally support `**kwargs`

---

## Example: Quantile Plot

```python
from scipy import stats

def quantile_plot(x, **kwargs):
    quantiles, xr = stats.probplot(x, fit=False)
    plt.scatter(xr, quantiles, **kwargs)

g = sns.FacetGrid(tips, col="sex")
g.map(quantile_plot, "total_bill")
```

# 25. Practical Color Guidelines

## Use Hue For:

* Categories
* Classes
* Groups

## Use Luminance For:

* Magnitude
* Density
* Importance
* Heatmaps

## Avoid:

* Too many categories
* Red-green combinations
* Overly saturated palettes
