# Seaborn API Reference (Structured Documentation)

## 1. Objects Interface

### Plot Object

| Component | Description                                               |
| --------- | --------------------------------------------------------- |
| `Plot`    | Declarative interface for specifying statistical graphics |

---

## 2. Mark Objects

### Dot Marks

| Object | Description                                        |
| ------ | -------------------------------------------------- |
| `Dot`  | Dot plots or sparse scatterplots                   |
| `Dots` | Stroke-based dots for better overplotting handling |

### Line Marks

| Object  | Description                                   |
| ------- | --------------------------------------------- |
| `Line`  | Connects points sorted along orientation axis |
| `Lines` | Faster but less flexible multi-line mark      |
| `Path`  | Connects points in input order                |
| `Paths` | Faster version for many paths                 |
| `Dash`  | Oriented segment for each datapoint           |
| `Range` | Line between min/max values                   |

### Bar Marks

| Object | Description                         |
| ------ | ----------------------------------- |
| `Bar`  | Bar between baseline and data value |
| `Bars` | Faster bar mark for histograms      |

### Fill Marks

| Object | Description                           |
| ------ | ------------------------------------- |
| `Area` | Filled region from baseline to values |
| `Band` | Filled interval between values        |

### Text Marks

| Object | Description                       |
| ------ | --------------------------------- |
| `Text` | Annotate or represent data values |

---

## 3. Statistical Transformation Objects

| Object    | Description                             |
| --------- | --------------------------------------- |
| `Agg`     | Aggregate data along value axis         |
| `Est`     | Point estimate with confidence interval |
| `Count`   | Count observations within groups        |
| `Hist`    | Histogram binning/counting              |
| `KDE`     | Kernel density estimation               |
| `Perc`    | Replace observations with percentiles   |
| `PolyFit` | Polynomial regression fitting           |

---

## 4. Move Objects

| Object   | Description                           |
| -------- | ------------------------------------- |
| `Dodge`  | Separate overlapping marks            |
| `Jitter` | Random displacement to reduce overlap |
| `Norm`   | Divisive scaling after aggregation    |
| `Stack`  | Stack overlapping marks               |
| `Shift`  | Uniform positional displacement       |

---

## 5. Scale Objects

| Scale        | Description                 |
| ------------ | --------------------------- |
| `Boolean`    | Scale for True/False values |
| `Continuous` | Numeric continuous scale    |
| `Nominal`    | Categorical scale           |
| `Temporal`   | Date/time scale             |

---

## 6. Base Classes

| Base Class | Description                          |
| ---------- | ------------------------------------ |
| `Mark`     | Base for visual data marks           |
| `Stat`     | Base for statistical transformations |
| `Move`     | Base for positional transforms       |
| `Scale`    | Base for visual property mapping     |

---
