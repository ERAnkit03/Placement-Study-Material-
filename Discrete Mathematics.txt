# 4. Discrete Mathematics for AI/ML Development

Discrete Mathematics is the mathematics of **countable and logical structures**.

It is extremely important in:

* Machine Learning
* Algorithms
* Graph Neural Networks
* Search Engines
* LLMs
* Recommendation Systems
* Computer Science Foundations

Unlike calculus (continuous math), discrete math works with:

* separate values
* logic
* structures
* graphs
* combinations

---

# 4.1 Sets

## Definition

A set is a collection of unique elements.

Example:

A = {1,2,3,4}

---

# Important Set Operations

| Operation    | Meaning                |
| ------------ | ---------------------- |
| Union        | Combine sets           |
| Intersection | Common elements        |
| Difference   | Remove elements        |
| Subset       | One set inside another |

---

# Union

Combines all elements.

Example:

A = {1,2,3}

B = {3,4,5}

Union:

A U B = {1,2,3,4,5}

---

# Intersection

Common elements.


A ^ B = {3}


---

# 4.2 Relations

## Definition

A relation connects elements between sets.

Example:

If:

 A = students
 B = courses

Relation:
“student enrolled in course”

---

# Mathematical Representation


R = {(a,b)}


where:
a relates to b

---

# AI/ML Usage

Used in:

* knowledge graphs
* graph databases
* recommendation systems
* relational learning

Example:
Netflix recommendation:
(User → watched → Movie)

# 4.8 Combinatorics

Combinatorics studies counting and arrangements.

Very important in probability and ML.

---

# A. Permutations

Order matters.

Formula:

P(n,r)= n! / (n-r)!

---

# Example

Arrange 3 letters from A,B,C,D.

---

# B. Combinations

Order does NOT matter.

Formula:

C(n,r)=n! / r! (n-r)!

---

# AI/ML Usage

Used in:

* feature selection
* probability
* hyperparameter combinations
* search spaces

---

---

# AI/ML Usage

# 4.10 Complexity Basics

# A. Big-O Notation

## Definition

Big-O describes algorithm growth rate.

---

# Common Complexities

| Complexity | Meaning     |
| ---------- | ----------- |
| O(1)       | Constant    |
| O(log n)   | Logarithmic |
| O(n)       | Linear      |
| O(n²)      | Quadratic   |
| O(2ⁿ)      | Exponential |

---

# Example

Searching in list:

* linear search → O(n)
* binary search → O(log n)
